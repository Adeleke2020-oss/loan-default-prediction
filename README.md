Loan Default Prediction

Project Overview

This project focuses on analysing loan data to understand the factors that contribute to loan defaults.

Objectives

* Explore and understand loan datasets.
* Clean and prepare data for analysis.
* Identify patterns associated with loan defaults.
* Apply data analytics techniques to extract insights.

Tools and Technologies

* Python
* Pandas
* SQL
* SQLite
* Google Colab

Project Structure

* notebooks/ – Jupyter notebooks and analysis.
* data/ – Dataset files.
* sql/ – SQL queries.
* reports/ – Project findings and reports.

Project Status

In progress.
